# Story Estimates

Story Estimates let your team size work items collaboratively. Everyone votes on
a story using a shared point scale, votes are hidden until the facilitator
reveals them all at once, and the team agrees on a final estimate. The process
repeats — one round per ticket — until the session is complete.

![Story Estimates overview: the session list with ongoing and history cards](/story-estimates/overview-annotated.png)

1. **Start Estimating** — opens the four-step wizard to create a new session.
2. **Group / Sort / Layout toolbar** — controls how sessions are grouped, sorted, and displayed.
3. **Ongoing session card** — join an active session with the Join Session button.
4. **Completed session card** — open a past session report.

## How it works

1. **Create a session** — pick a point-scale template, choose a team, set a name
   and optional sprint link. The session opens in the _Waiting_ state.
2. **Start a round** — the facilitator enters a ticket number (e.g. `PROJ-123`)
   to open voting for that story.
3. **Vote** — each participant clicks a card from the point scale. Votes are
   hidden from others until revealed.
4. **Reveal** — the facilitator clicks **Reveal Votes**. All votes appear at
   once, with statistics (average, range).
5. **Agree on a number** — the facilitator sets **Agreed Points** for the story.
6. **Repeat** — start the next round for the next ticket.
7. **End the session** — click **End Session** to close voting and produce the
   session report.
