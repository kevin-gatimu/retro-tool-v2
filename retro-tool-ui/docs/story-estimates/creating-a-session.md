# Creating a session

Any team member can start a story estimate session for a team they belong to.

## Steps

Click **Story Estimate** in the sidebar, then click **Start Estimating** (top
right). A four-step wizard opens.

### Step 1 — Template

Choose the point scale for the session.

The **Default story estimate values** template is selected automatically. It
uses the scale: **0, ½, 1, 2, 3, 5, 8, 13, 20, 40, 100, ?, ☕**

Additional global templates (Fibonacci, Modified Fibonacci, Powers of 2,
T-shirt Sizes, Hours, Days) and any templates your organisation has created are
listed below. Scroll or page through to find one, then click it to select it.

### Step 2 — Team

Click the team you want to run the session for. Each card shows the team name,
organisation, and your role on that team.

### Step 3 — Settings

Configure the session details:

![Settings step of the wizard: session name, sprint link, and timer fields](/story-estimates/create-step3-settings-annotated.png)

1. **Session Name** — required; shown in the session list and report header.
2. **Sprint Link** — optional URL to your sprint board (must start with `http://` or `https://`).
3. **Default Timer per Story** — countdown that auto-starts when each round begins (None, 1–5 min).

| Field                   | Required | Notes                                                                                         |
| ----------------------- | -------- | --------------------------------------------------------------------------------------------- |
| Session Name            | Yes      | Shown in the session list and report header.                                                  |
| Sprint Link             | No       | Must start with `http://` or `https://`. Shown as "Open sprint board" inside the session.     |
| Default Timer per Story | No       | Countdown that auto-starts when each round begins. Options: None, 1 min, 2 min, 3 min, 5 min. |

### Step 4 — Confirm

Review your choices. Use **Back** to adjust any step, or click **Create
Session** to open the session.

::: tip Timer behaviour
The timer starts automatically when the facilitator clicks **Start Round**. It
counts down to zero and stops — it does not end the round automatically. You
can still vote or reveal after the timer expires.
:::
