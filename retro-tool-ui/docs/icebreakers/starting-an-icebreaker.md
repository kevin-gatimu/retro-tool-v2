# Starting an icebreaker

From the icebreaker list (`/icebreakers`), click **Start Icebreaker** to open
the new-session form.

![New icebreaker form: session details and prompt source](/icebreakers/new-icebreaker-annotated.png)

1. **Session name** — pre-filled with the current day/date/time (e.g.
   "Monday 20th July - 8pm"), fully editable.
2. **Team** — the team the session belongs to. Only that team's members can
   join it.
3. **Prompt source** — how prompts for the deck are chosen (see below).

Click **Create icebreaker** once a name, a team, and a valid prompt source
are set. You land straight in the session runner.

## Choosing how prompts are picked

| Mode                | What it does                                                                                                                                                                                             |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Pick a template** | Uses every prompt from a chosen built-in or org deck, in that deck's order. Pick one of the template cards shown — each shows its name, flavour badge (Fun / Professional / Creative), and prompt count. |
| **Random mix**      | Shuffles the built-in prompt pool (reproducibly, by a seed). You can optionally narrow it to a **flavour** — Any, Fun, Professional, or Creative.                                                        |
| **Write your own**  | Author one-off prompts just for this session (2–20, up to 500 characters each) — they aren't saved as a reusable template.                                                                               |

::: tip Starting from a standup
An icebreaker can also be started from inside a standup day's room — the
dialog there mirrors this same form (name, and the same three prompt-source
modes), but the team is fixed to the standup's team and the session is
linked to that day's feed.
:::
