# Roles and permissions

| Action                                          | Team member | Team lead | Org owner/admin | System/super admin |
| ----------------------------------------------- | :---------: | :-------: | :-------------: | :----------------: |
| View and join an active session                 |     ✅      |    ✅     |       ✅        |         ✅         |
| Start an icebreaker                             |     ✅      |    ✅     |       ✅        |         ✅         |
| Browse the swipe deck (Skip / Select / Shuffle) |   if host   |    ✅     |       ✅        |         ✅         |
| Advance to the next prompt / finish             |   if host   |    ✅     |       ✅        |         ✅         |
| End a session early                             |   if host   |    ✅     |       ✅        |         ✅         |
| React during the celebration bar                |     ✅      |    ✅     |       ✅        |         ✅         |

**Starting** an icebreaker has no role restriction — any team member can
start one. **Managing** a session in progress — driving the swipe deck,
advancing prompts, finishing, or ending early — is restricted to whoever can
manage it:

- the session's **host** (whoever created it),
- a **team lead** on the session's team,
- an **org owner or admin** of that team's organization, or
- a **system or super admin**.

Everyone else who joins the session watches the same live state (waiting,
curating, presenting, completed) but can only react during the celebration
bar — they can't drive the deck or end the session.
