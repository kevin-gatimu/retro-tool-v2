# Reactions and celebration

When a prompt is on screen (the **Presenting** phase), the team answers it
out loud — there's no in-app text response to type. Instead, anyone in the
session can react to a great answer with a burst of confetti.

![Presenting a prompt with the celebration bar](/icebreakers/presenting-annotated.png)

1. **Prompt card** — the selected prompt, shown large for the whole team to
   discuss together.
2. **Celebration bar** — three reactions with escalating intensity:
   **Celebrate** 🎉, **Applause** 👏, and **Fire** 🔥. Clicking one launches a
   confetti-and-emoji burst from that button, on your screen and everyone
   else's in the session at the same time.
3. **Next prompt / Finish** — host-only. Moves to the next pending prompt
   (back into curating) or, if none remain, finishes the session.

Reactions are momentary — they aren't saved anywhere and don't appear in any
report; they're purely a live, shared visual moment during the session.
