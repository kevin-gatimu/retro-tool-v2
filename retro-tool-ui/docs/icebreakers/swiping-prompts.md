# Swiping prompts

Once a session moves into **Curating**, the host sees a swipe deck of the
session's pending prompts. Anyone else on the team sees a "Host is picking a
prompt" waiting state instead — only the host can drive the deck.

![Swipe deck: browsing prompts and deciding the one on screen](/icebreakers/swipe-deck-annotated.png)

1. **Card stack** — the current prompt is on top, with a faint peek of the
   next card behind it. Drag the card left/right (or use the ← / → arrow
   buttons, or the keyboard arrow keys) to **browse** between pending
   prompts — this doesn't decide anything, it just moves which card is on
   screen.
2. **Skip / Shuffle / Select** — act on the card currently on screen:
   - **Skip** discards it — it's marked as decided and dropped from the
     deck.
   - **Shuffle** re-randomizes the local browsing order (doesn't touch which
     prompts are still pending).
   - **Select** puts that prompt up for discussion — the session moves to
     **Presenting** with that prompt on screen for everyone.
3. **Progress dots** — one per pending prompt, showing which card in the
   stack you're currently viewing.

A progress bar above the deck ("N/M prompts") tracks how many of the
session's total prompts have been decided (kept or skipped) so far.

::: tip Nothing is decided until Skip or Select
Browsing with drag, arrows, or the keyboard never commits anything — only
clicking **Skip** or **Select** on the card that's on screen decides it.
:::
