# Ending a session

There are two ways a session stops running, and both **immediately and
permanently delete it** — there is no report, recap page, or history entry
left behind afterwards.

## Finishing the deck

While presenting the last kept prompt, the host's **Next prompt** button
becomes **Finish**. Clicking it hard-deletes the session right away — the
host is taken straight back to the icebreaker list with a "Icebreaker
finished" confirmation. Anyone else still in the session is redirected out
the moment the session's live state disappears, with a toast explaining the
host ended it.

## Ending early

The host (or anyone who can manage the session) can also click **End
session** at any point before it's finished. A confirmation dialog warns how
many prompts in the deck are still undiscussed, since they'll be left
decided without ever being presented.

![End session confirmation dialog](/icebreakers/end-session-confirm-annotated.png)

1. **Warning text** — how many prompts are still pending and will be left
   undiscussed.
2. **Cancel** — closes the dialog without ending anything.
3. **End session** — confirms, hard-deleting the session immediately.

::: warning This can't be undone
Whether you finish the deck or end early, the session is **hard-deleted**.
Everyone still in the runner is redirected back to the icebreaker list with
a toast explaining the host ended it. Take notes elsewhere during the
session if you want to remember what was discussed.
:::
