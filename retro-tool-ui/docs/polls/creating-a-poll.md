# Creating a poll

Any member of a team can create a poll for that team.

## Steps

1. Go to **Polls** in the sidebar and click **New Poll** (top right).

2. The **Create Poll** dialog opens. Fill it in:

   ![The Create Poll dialog with each field numbered](/polls/create-dialog-annotated.png)
   - **Team** — if you belong to more than one team, pick which team the poll is
     for. (With a single team, this is chosen for you and the picker is hidden.)
   - **Question** — what you're asking, e.g. _"How are you feeling today?"_ (up
     to 500 characters).
   - **Options** — the answers people can choose from. Each option can have an
     optional **emoji** and a **label**. You start with two; add up to **10**
     with **Add option**, or remove one with the ✕ (a poll always needs at least
     two).
   - **Anonymous poll** — tick this to hide who voted for what. Leave it
     unchecked for a public poll where voters' names are visible. See
     [Results & anonymity](./results-and-anonymity).

3. Click **Create Poll**. The poll appears immediately in the list for everyone
   on the team.

::: tip Choosing anonymous
Anonymity is set when you create the poll and shown on the card (an
**Anonymous Poll** / **Public Poll** label). Editing a poll can change it, but
keep in mind people may have voted already expecting the original setting.
:::

## What each field means

| Field     | Required | Notes                                                     |
| --------- | -------- | --------------------------------------------------------- |
| Team      | Yes      | The poll belongs to this team; only its members can vote. |
| Question  | Yes      | 1–500 characters.                                         |
| Options   | Yes      | 2–10 options; each needs a label, emoji optional.         |
| Anonymous | No       | Off = public (voter names shown); on = anonymous.         |
