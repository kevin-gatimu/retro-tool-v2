# Polls

Polls are quick team questions — ask something with a fixed set of answers, and
watch the results update live as people vote. Use them for pulse checks ("How
are you feeling this sprint?"), quick decisions ("Which day works for the
demo?"), or anything you'd otherwise ask in a thread.

Polls are **team-scoped**: each poll belongs to a team, and that team's members
can see and vote on it. They can be **public** (everyone sees who voted for what)
or **anonymous** (votes are counted but voters are hidden).

## Where to find polls

Open **Polls** from the sidebar (under **Engagement**). The page lists every
poll across the teams you belong to. If a poll is attached to a standup, it also
appears in that standup's daily room.

::: tip
You need to belong to at least one team to create a poll. If the **New Poll**
button is disabled, join or create a team first.
:::
