# Creating a retrospective

Any member of a team can create a retrospective for that team.

## Steps

1. Open **Retrospectives** in the sidebar and click **New Retrospective**
   (top right).

2. **Step 1 — Template.** Choose a retrospective format. Built-in templates
   are shown under **Global Templates** (paginated, 6 per page); any templates
   your organisation has created appear under **Your Organization**.

   ![Template selection step showing built-in template cards](/retrospectives/new-retro-template-annotated.png)

   | Template                    | Columns                                                                |
   | --------------------------- | ---------------------------------------------------------------------- |
   | **Start / Stop / Continue** | Start, Stop, Continue                                                  |
   | **4Ls**                     | Liked, Learned, Lacked, Longed For                                     |
   | **Mad / Sad / Glad**        | Mad, Sad, Glad                                                         |
   | **DAKI**                    | Drop, Add, Keep, Improve                                               |
   | **5 Whys**                  | Problem, Why #1, Why #2, Why #3–5, Action                              |
   | **Sailboat**                | Wind, Anchor, Rocks, Sun                                               |
   | **FLAP**                    | Future Considerations, Lessons Learned, Accomplishments, Problem Areas |
   | _(+ more)_                  | Built-in library ships over a dozen formats                            |

   Click any card to select it; the selection is highlighted with a ring. Click
   **Next** once a template is chosen.

3. **Step 2 — Team.** Pick which team the retro is for. Teams you belong to are
   shown; click a card to select it. Click **Next**.

4. **Step 3 — Settings.** Configure the session options:

   ![Settings step with each field labelled](/retrospectives/new-retro-settings-annotated.png)

   | Setting                 | Default                 | Notes                                                                                                                                         |
   | ----------------------- | ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
   | **Retrospective Name**  | `<Template name> Retro` | Optional; leave blank to use the default.                                                                                                     |
   | **Card Creation Timer** | 5 minutes (on)          | When enabled, cards are hidden from other participants until the timer expires. Toggle the switch to disable entirely, or change the minutes. |
   | **Anonymous Mode**      | On                      | When on, card authors are hidden to encourage honest feedback. When off, author avatars are visible on every card.                            |
   | **Votes per Person**    | 3                       | Each participant can cast up to this many thumbs-up votes during the voting phase. Pick 1–10.                                                 |

5. **Step 4 — Confirm.** Review all choices (template, team, settings summary)
   and click **Create Retrospective**. You are taken straight to the new retro
   in the **Draft** state.

::: tip Choosing anonymous mode
Anonymous mode is set at creation time and cannot be changed mid-session.
When in doubt, leave it on — it encourages honest feedback. The setting is
visible on the retro header at all times.
:::

::: tip Timer behaviour
When the card-creation timer is enabled, each participant's cards are shown
only to them until the timer expires. Once time is up (or the timer runs out
completely), all cards become visible to everyone. This prevents anchoring
during the brainstorm phase.
:::
