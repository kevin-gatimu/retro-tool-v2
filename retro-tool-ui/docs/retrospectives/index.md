# Retrospectives

Retrospectives give your team a structured space to reflect on a sprint or
period of work — surface what went well, what didn't, and turn the discussion
into concrete action items that carry forward to the next cycle.

![The Retrospectives list showing ongoing and completed retros](/retrospectives/retros-list-annotated.png)

1. **New Retrospective** — start a new retro.
2. **View toolbar** — group, sort, and switch layout.
3. **A retro card** — click to open; the badge shows its current phase.

## How it works

A retro moves through a fixed sequence of phases. The facilitator (creator or
team lead) controls the transitions; every participant sees the same board in
real time.

| Phase               | What happens                                                                                                        |
| ------------------- | ------------------------------------------------------------------------------------------------------------------- |
| **Draft**           | Retro created; only the facilitator sees it.                                                                        |
| **Waiting (Lobby)** | Lobby is open; participants join and the facilitator waits. Auto-starts on a countdown.                             |
| **Adding Cards**    | Everyone adds cards to each column. A timer hides cards until it expires.                                           |
| **Grouping**        | Similar cards are merged before voting begins.                                                                      |
| **Voting**          | Everyone votes on cards (up to the configured maximum).                                                             |
| **Discussing**      | One card at a time — the facilitator walks the queue, highest-voted first, while anyone can leave discussion notes. |
| **Completed**       | The report is available: discussed / not discussed / carried-forward cards, stats, PDF export, and email.           |

## Where to find retrospectives

Open **Retrospectives** in the sidebar under **Ceremonies**. The list shows
ongoing sessions at the top and completed ones below (collapsed by default —
click **Completed** to expand). You can search by name and filter by group or
sort order using the toolbar.

::: tip
You must belong to at least one team to create a retrospective. If **New
Retrospective** is not available, join or create a team first via **Teams** in
the sidebar.
:::
