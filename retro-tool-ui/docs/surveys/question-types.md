# Question types

Every survey question is one of three types. The type is chosen when the
question is created and determines how it's answered and how its results are
summarized.

## Text

A free-form answer, entered in a multi-line text box (up to 2,000 characters
when answering).

- **Results:** every individual text answer is listed as-is under the
  question (author never shown alongside the text — the answer stands on its
  own even on non-anonymous surveys).

## Rating

A 1–5 scale, answered by clicking stars.

- **Results:** a per-value (1 through 5) count and percentage bar, plus the
  average rating (e.g. "avg 3.5 / 5").

## Multiple choice

A single answer picked from a fixed list of 2–10 options (radio buttons).

- **Results:** a per-option count and percentage bar.

![Answering a Text, a Rating, and a Multiple choice question](/surveys/responding-annotated.png)

1. **Text** — free-form answer.
2. **Rating** — click a star to set 1–5; the current value shows to the right.
3. **Multiple choice** — pick one option; the selected option is highlighted.
4. **Submit response** — enabled once every required question is answered.

## Required questions

Each question can be marked **Required** when the survey is created. A
required question must be answered before the response can be submitted —
attempting to submit with a required question unanswered shows an inline
error on that question and a summary message ("Please answer all required
questions.").
